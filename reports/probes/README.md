# Hand-written probes

Own examples (not benchmark items) used to reproduce failure classes seen in
aggregate diagnostics. `noul_generic_criteria.json`: short factual record
with generic true/false criteria — the Noul head answered "no" for supported
propositions before Noul class balancing. `intent_thin_evidence.json`: a
damage report matching only one incidental word of a wrong option — the
Choice answer was p = 1.0 before the evidence-sensitive temperature.
